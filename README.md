# WEI JIA — Portfolio

韦佳的个人设计作品集，包含品牌形象、交互设计、包装、字体、书籍和海报作品。

网站源文件位于 `site/`，无需安装依赖或构建。

## 预览

在仓库目录运行 `python -m http.server 8080 --directory site`，访问 `http://localhost:8080`。

## 部署

GitHub 仓库 Settings → Pages → Source 选择 GitHub Actions。
推送到 `main` 后，Pages 工作流自动发布网站。

网站地址：https://wjia6032-debug.github.io/portfolio/
